# Universe Daily — website

The web version of [Universe Daily](https://apps.apple.com/us/app/universe-daily/id6751823874) for iPhone, served at www.app.kportal.net.

- **Today:** NASA's Astronomy Picture of the Day, live sky data, the latest space news
- **Explore:** People in Space, ISS Tracker, Upcoming Launches, Night Sky Conditions, Spacecraft, Eclipses
- **News**, **Support** and the **Privacy Policy**

It's a static site with no build step: plain HTML, CSS and JavaScript modules. Push the files to the repository's GitHub Pages branch and it's live. Press `?` on the site to see keyboard shortcuts.

To preview locally:

```bash
python3 -m http.server 8765
```

Then open http://localhost:8765.
